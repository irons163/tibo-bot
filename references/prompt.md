# Tibo Bot 生成提示詞

依序使用主提示詞、符合服裝選項的一段，以及符合腮紅選項的一段。三張影像依序是使用者主圖、Tibo 姿勢參考、Bot 畫風參考。

## 主提示詞

```text
製作 1:1 的 Tibo Bot 風格頭肩大頭照，整張圖都必須是簡潔的 2D 平面向量插畫，而不是照片或 3D。影像 1 是使用者提供的唯一主體，將其轉成插畫並保留可辨認的髮型、髮色、膚色與原有配件；只保留原圖中實際存在、可獨立於服裝的配件，例如眼鏡、髮飾、耳飾。衣領、領帶、胸針及其他服裝細節依下方服裝設定決定。影像 2 只作 Tibo 姿勢與構圖參考，提供臉部朝向、頭肩位置與暖色背景。服裝另依使用者的選項決定。不要複製影像 2 的人物或臉，也不要沿用影像 2 的攝影質感。影像 3 的正面直頭姿勢與構圖一律忽略。

依影像 2 的完整畫面安排姿勢，以下方向均以觀看者為準：
1. 頭頂向畫面右傾，下巴朝左下，雙眼中心的連線約向右下傾 12–15°。左右轉臉與上下俯仰分開匹配：臉大致朝向鏡頭，保留範例輕微的左右透視差，從臉頰輪廓和耳朵的遮擋呈現，下巴保持自然，避免做成明顯側臉或仰頭。
2. 頭部偏在畫面右上，胸口留在頭部的左下方，左側留白明顯多於右側。以整張正方形為基準，雙眼中心的中點約落在從左 61%、從上 40% 的位置。頭頂留白約六分之一，依原主體的自然髮型微調；避免把臉放在畫面正中央或放大成特寫。
3. 軀幹是獨立的姿勢要求。照影像 2 重畫從頸根到肩膀與上胸的角度、位置和輪廓。胸口近正面，兩肩都放鬆，畫面左肩較高，肩線向右微降，身體的斜度小於頭部側傾。胸口中心在頭部中心左下方，衣領中心約在畫面橫向中間。左肩的外輪廓落在畫面左下，右肩順勢延伸至畫面右下角。保留影像 2 的上胸裁切，手臂自然垂在畫面外。不要沿用影像 1 的側身、前伸的肩膀、上臂透視或抱胸姿勢，也不要把整個上身跟著頭一起傾斜。這些要求適用於兩種服裝選項。

影像 3 只提供 2D 插畫的畫風與簡化臉部造型：柔和單色膚色的簡潔圓臉、兩隻黑色直立長橢圓眼睛，沒有鼻子、嘴巴、牙齒或其他五官。臉部為單一平面膚色，耳朵與脖子可以使用相近、略深的膚色作為簡單平面色塊。人物的臉、頭髮和衣服以俐落平面色塊呈現，不要漸層、反光、立體陰影、紋理、毛髮細絲、塑膠或陶瓷材質、3D 渲染和寫實攝影。髮型髮色、膚色與原有配件來自影像 1，不能照抄影像 3 的角色。耳朵依影像 3 的遮擋關係：臉頰與耳朵之間有一小束側髮，側髮在最前方，耳朵在側髮後方。只從髮絲外側露出一點窄窄的小月牙，上下收尖，幅度低調。露出的耳朵由雙層平面色塊組成：外沿與臉同色，淡桃膚色的內耳緊貼髮際，讓髮絲截斷內緣。不要把內耳畫成一個完整的圓點或獨立橢圓，也不要描邊。髮型原本遮住耳朵時，維持自然遮擋。兩眼隨 Tibo 的歪頭姿勢一起傾斜；保持完整頭部和肩膀。

背景以影像 2 的 Tibo 大頭照為準，匹配它的柔和暖米灰、米色、暖棕與淡灰綠，保留上方暖棕、下方較淺暖灰綠的柔和漸變及位置；背景無物件。只讓背景使用柔和漸變，人物仍保持 2D 平面色塊；不要改用影像 3 的單一米色背景。輸出完整頭肩，保留頭部和下巴，不加外框、額外文字、浮水印或拼貼。

臉部色塊使用中性光下的低飽和膚色，與暖色背景獨立。以影像 1 的臉部中間調保留人物本來的膚色深淺和底色。對偏黃橘的自然膚色，請把橙色色度明顯壓低，約減少三分之一到一半，以同等明度的中性米膚色、米棕或柔和褐色作為底色。舉例，中等膚色可參考 #DDB59E 的中性米棕色調；色碼僅用來說明去橘方向，依原人物的膚色深淺調整。臉部底色應讀成自然膚色，避免蜜桃橘、粉橘或曬紅感。調整的是色偏，深色膚色維持原來的深度，保留非人類角色本來的非自然膚色。外耳與臉使用同一基準色，內耳和脖子使用相近的稍深色塊。腮紅依選項決定，只影響兩小片臉頰。
```

## Tibo 黑衣（預設）

```text
Tibo 黑衣：穿影像 2 的素黑色圓領上衣。將影像 1 的所有衣物和服裝細節全部換掉，胸前只呈現一件素黑色圓領上衣。移除外套、襯衫、翻領、領帶、領結、制服及胸針，保留原照的髮型、膚色及與服裝無關的原有配件。成品胸口與兩肩都穿純黑上衣，無圖案或標誌。
```

## 保留原本衣服

```text
保留原本衣服：服裝依影像 1，保留可見的原衣顏色、款式、領型、圖案及層次。把影像 1 當衣款參考，姿勢與構圖完全依影像 2。
先依影像 2 畫好近正面的上胸與放鬆的肩膀，保留頭部偏右、胸口偏左、肩線稍向右下的相對位置。再把原衣畫到這個軀幹上，重新安排領口、門襟、衣縫和圖案的透視。若原衣有翻領或門襟，領口的開口和門襟要對齊胸口中心，不能被歪頭帶到畫面右側。若有橫條紋，讓它沿胸前自然連續，只隨肩線微斜。雙臂向下並留在畫面外，左袖不可前伸擋住胸前；不要照搬原照片的側身、突出肩膀、袖子輪廓或抱胸衣褶。服裝不能改變肩線、胸口朝向或裁切。
忽略影像 2 和影像 3 的黑衣。裁切外只自然延續已知款式；原圖完全看不到衣服時，用簡單中性色上衣補足，不憑空添加圖案或標誌。
```

## 加腮紅（預設）


```text
關閉腮紅：雙頰和其他臉部區域同色，不畫腮紅、粉點、紅暈或臉頰陰影，即使影像 3 有腮紅也忽略。保留小耳朵的兩層色塊。
```
